CE223 - Earthquake Protective Systems

What this is about

  • Characterize base isolation and energy dissipation and predict seismic response.
  • Two strands: (1) base isolator design — from test curves to equivalent SDOF and earthquake response; (2) SDOF damping models — compare viscous, hysteretic, and fractional damping.
  • Each step has an interactive dashboard linked below.

Base isolator strand

  • 4 HDR bearings support a rigid mass. Test data: force–displacement loops at several strain levels.
  • Step (a): Digitize loops → get \(K_1\), \(K_2\), \(\zeta_{\mathrm{eff}}\) vs shear strain.
  • Step (b): Equivalent SDOF with \(k = 4K_1\). Iterate: assume peak displacement → read \(K_1\), \(\zeta_{\mathrm{eff}}\) → run Newmark → update peak → repeat until convergence.
  • Step (c): Same SDOF solved with FFT; compare to Newmark.

Two dashboards: hysteresis metrics (Step a), then iteration and Newmark vs FFT (Steps b–c).

SDOF damping models strand

  • Compare three models: Kelvin–Voigt (viscous), hysteretic, fractional Kelvin–Voigt.
  • Under harmonic displacement: loops, \(K_1(\omega)\), \(K_2(\omega)\), EDC vs \(\omega\).
  • Under earthquake: frequency-domain response using the correct \(\hat{R}(\omega)\) for each model.

Full dashboard (theory + loops + EDC + earthquake) and a compact loops-only view.

Concepts

  • Hysteresis: loop area \(\oint f\,du\) = energy per cycle; links to loss stiffness \(K_2\).
  • Equivalent SDOF: peak displacement → strain → \(K_1\), \(\zeta_{\mathrm{eff}}\); system \(k = 4K_1\) (4 bearings).
  • Newmark vs FFT: same SDOF; time-domain step-by-step vs frequency-domain \(U(\omega) = H(\omega)\,\ddot{U}_g(\omega)\).
